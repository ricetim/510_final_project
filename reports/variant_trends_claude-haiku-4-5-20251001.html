1. Pairwise agreement matrix

What this shows: For every pair of demographic variants, the fraction of scenarios on which both gave the same Yes/No verdict.

How it’s computed:

  • For each variant v on each scenario s, yes-rate(v, s) = #Yes / (#Yes + #No) across the n = 5 replicates.
  • majority(v, s) = Yes if yes-rate > 0.5, No if < 0.5, undefined if exactly 0.5 (exactly-tied variants are excluded from that pair’s count).
  • Cell (vi, vj) = #scenarios where both majorities are defined and equal ÷ #scenarios where both are defined.
  • Diagonal is trivially 1.00 — a variant always agrees with itself.

Row mean (excl. self): Average of the 14 off-diagonal cells in each row. Quantifies how aligned this variant is with the others on average. A low row mean flags an outlier variant whose majorities frequently disagree with the rest; a high row mean indicates a variant that sits in the consensus.

How to read it: Hot cells = answer together, cold cells = answer opposite. The row-mean column condenses each variant into a single “how central is this variant” score on the same color scale as the matrix.

2. Spearman rank correlation

What this shows: For every pair of variants, the rank correlation between their per-scenario yes-rates. Captures partial agreement that method 1’s majority-only view discards.

How it’s computed:

  • Treat each variant as a length-N vector of yes-rates (one value per scenario).
  • Replace each value with its rank (1 = lowest yes-rate, N = highest). Ties receive mid-ranks — e.g. three tied values share rank 5 each, not 4/5/6.
  • Cell (vi, vj) = Pearson correlation between vi’s rank vector and vj’s rank vector.
  • Range: −1 (perfectly opposite movement) through 0 (no monotonic relationship) to +1 (perfectly aligned movement). Diagonal is 1.00.

Why both this and method 1: Variant A with yes-rates (0.8, 0.6, 0.2) and variant B with (0.7, 0.5, 0.1) have identical Yes/Yes/No majorities, so method 1 scores them 100%. Spearman additionally detects that their yes-rates move in lockstep across scenarios — a stronger statement than “they happened to land on the same side of 0.5 three times.”

Row mean (excl. self): Average of the 14 off-diagonal Spearman values in each row. Quantifies how strongly this variant’s yes-rate co-varies with the others on average. A low row mean flags a variant that marches to its own beat; a high one indicates a variant whose answer pattern broadly tracks the rest.

How to read it: Blue cells = answer together (positive ρ); red cells = answer opposite (negative ρ); pale cells = independent.
